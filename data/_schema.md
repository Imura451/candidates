# 候補者JSON 項目の説明書

`data/<id>.json` に書く各項目の意味と書き方です。記入例は `data/_sample.json` を見てください。

ページに載るのは「顔写真」「簡単な候補者情報」「インタビュー動画」の3点だけです。
詳しい経歴・資格は履歴書で別途お渡しする前提なので、ここには書きません。

## 共通のルール

- **空欄はページに出ません。** 空文字 `""` にするか、項目ごと消してください
- **値＋補足の書き方。** 基本情報の各項目は「値だけ」でも、「値＋補足」でも書けます

  ```json
  "japanese": "JLPT N4 合格"
  "japanese": { "value": "JLPT N4 合格（2026年7月）", "note": "作業指示は聞き返さずに理解できます" }
  ```

- **数字は半角。** 「3年」「26歳」
- **載せてはいけないもの。** フルネーム、番地までの住所、生年月日、パスポート番号、在留カード番号、家族の実名

---

## 全体

| 項目 | 必須 | 説明 | 例 |
|---|---|---|---|
| `id` | **必須** | 候補者の識別子。**他の候補者と重複させない。** 半角英数とハイフン | `vn-02` |
| `draft` | | `true` のあいだはページ上部に赤い帯「サンプル／下書きです」が出る。社外に出す前に `false` にするか行ごと消す | `true` |
| `updated` | | 更新日。ページ右上と社内一覧に出る | `"2026-09-15"` |
| `comment` | | **任意。** 聞き手（井村）として会って感じたことを2〜3行。空ならセクションごと出ない。改行はそのまま反映される | |

`_` で始まる項目（`"_使い方"` など）はメモ扱いで、ページには出ません。

## basic（顔写真の横に出る名前まわり）

| 項目 | 必須 | 説明 | 例 |
|---|---|---|---|
| `displayName` | **必須** | 表示名。**名＋姓のイニシャル**にする。フルネームは書かない | `"ホアン T."` |
| `nationality` | | 国籍（日本語） | `"ベトナム"` |
| `countryCode` | **必須** | 国コード2文字。国旗の表示と、URLの先頭に使う。`VN` `PH` `BD` `ID` `LK` `NP` `GH` | `"VN"` |
| `age` | | 年齢（数字） | `26` |
| `gender` | | 性別 | `"男性"` |
| `location` | | 現在地。国名から書く。在日中なら「在留中」と入れると「在住」が重複しない | `"日本・愛知県（在留中）"` |

---

## info（簡単な候補者情報・5項目）

| 項目 | 必須 | 説明 | 例 |
|---|---|---|---|
| `desiredJob` | **必須** | 希望職種。名前の下に大きく出る | `"溶接（半自動アーク・被覆アーク）"` |
| `visa` | | 在留資格（予定を含む）。試験合格の有無を `note` に | 値＋補足 |
| `japanese` | | 日本語（JLPTと合格年月） | 値＋補足 |
| `experience` | | 実務経験の年数と内訳 | 値＋補足 |
| `availableFrom` | | 入社可能時期 | 値＋補足 |

`desiredJob` 以外の4つは表になります。値の無い行は自動で消えます。

## video（インタビュー動画）

| 項目 | 必須 | 説明 | 例 |
|---|---|---|---|
| `youtube` | **必須** | 動画のURL。**YouTube に「限定公開」でアップロードしたもの。** `youtu.be/…` でも `youtube.com/watch?v=…` でも、IDだけでもよい | `"https://youtu.be/xxxxxxxxxxx"` |
| `duration` | | 動画の長さ | `"約4分"` |
| `topics` | | この動画で話していることを3〜5行の配列。企業が「何が聞けるか」を見てから再生できる | `["日本語での自己紹介", "日本で働きたい理由"]` |
| `interviewer` | | 聞き手の表記。空なら「井村 稔（株式会社Minobordo 代表取締役）」 | |

`youtube` が空だと動画セクションは出ず、ビルド時に注意が表示されます。
YouTube の「限定公開」はURLを知っている人だけが見られる設定です。「公開」にしないでください。

## photos（顔写真）

写真は `assets/photos/<slug>/face.jpg` に置きます。`<slug>` はURLに使う「国コード＋8桁」の文字列（例 `vn-wy2t5ar3`）で、初回ビルドで決まります。
**一度 `node build.js` を実行すると、このフォルダが自動で作られる**ので、そこに写真を入れて、もう一度ビルドしてください。
どのフォルダが誰のものかは `docs/index.html`（社内用一覧）で確認できます。

| 項目 | 説明 |
|---|---|
| `face` | **空のままなら `face.jpg`（または .png .webp）を自動で使う。** 別の名前にしたときだけファイル名を書く |

写真は履歴書の写真と同じ縦4：横3の縦長で表示します（画面では横120px×縦160px、印刷では30mm×40mm）。履歴書用の写真をそのまま使えます。ビルド時にHTMLへ埋め込まれるので、1枚あたり300KB程度に縮小しておくとページが軽くなります。
